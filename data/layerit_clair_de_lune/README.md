# LayerIt: Debussy, *Clair de lune*, mm. 1–6

Files from the LayerIt and ScoreWarp demonstration on Maria João Pires's
recording of the first six measures of *Clair de lune* (Suite bergamasque,
third movement). The recording itself is not included.

| File | Content |
|---|---|
| `clair-de-lune M6-basic.mei` | The score of mm. 1–6 in MEI; every note carries an `xml:id`. |
| `ClairDeLune_MariaJoaoPires_untilM6.txt` | The score-to-audio alignment: 31 lines `onset_seconds<TAB>xml_id,…`, no trailing newline. |
| `ClairDeLune_MariaJoaoPires_untilM6.maps.json` | The same alignment in the MAPS format (TROMPA): rows `{obs_mean_onset, xml_id, obs_num}`. |
| `ClairDeLune_MariaJoaoPires_untilM6.svg` | The score engraved by Verovio 5.2.0 and warped by ScoreWarp to the performance's time, with a seconds axis (`g.timeAxis`). |
